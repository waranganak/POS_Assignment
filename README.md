

🛒 Aura Super City - POS System
A modern, responsive Point of Sale (POS) web application designed for efficient retail management. This project is built as a Single Page Application (SPA) to provide a seamless user experience for managing customers, items, and orders.

✨ Features
Single Page Architecture: Smooth navigation between Home, Customer, Item, and Order sections without page reloads.

Customer Management: Full CRUD (Create, Read, Update, Delete) operations for customer profiles.

Inventory Control: Manage item codes, stock levels (Qty), and pricing.

Dynamic Order Management:

Automated Invoice generation.

Real-time Total and Subtotal calculation.

Discount and Balance handling.

Interactive data tables using jQuery.

Responsive UI: Mobile-friendly navigation with a custom burger menu.

Advanced Inputs: Integrated Flatpickr for a professional date-picking experience.

🛠️ Tech Stack
Frontend: HTML5, CSS3 (Custom Grid/Flexbox styling)

Scripting: JavaScript (ES6 Modules)

Library: jQuery 3.6.0

External Plugins: Flatpickr (Date Picker)

Design Pattern: MVC (Model-View-Controller) logic implemented via separate JS controllers.

📂 Project Structure
/controllers: Handles logic for Home, Customers, Items, and Orders.

/models: Defines the data structure for entities.

/db: Centralized data storage (DB.js).

/css: Separate stylesheets for layout, login, and index.
